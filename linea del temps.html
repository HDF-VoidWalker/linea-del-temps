Les tres famílies

Microsoft

Des de MS-DOS i les primeres versions de Windows fins a Windows 11. L'evolució passa de sistemes molt limitats a plataformes de 64 bits i maquinari modern.

Apple

De System 1 i el Macintosh clàssic a Mac OS X i macOS. El canvi a Mac OS X va portar una base Unix i una arquitectura més moderna.

Linux

El nucli Linux va aparèixer el 1991. Per representar una família utilitzable en ordinadors personals, també es mostren versions d'Ubuntu, una distribució GNU/Linux.
